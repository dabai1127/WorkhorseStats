# 牛马统计

精致、轻量的 Windows 桌面使用统计小应用，记录一天的屏幕、软件、键盘和鼠标使用情况。数据保存在本机，无需账号，不连接网络。

当前版本：**1.1.1**。

## 快速开始

1. 双击本目录的 `牛马统计.exe`。
2. 保持程序运行，统计从启动时开始累计。
3. 点击日期箭头查看历史，点击「今天」返回当天。

支持 Windows 10 / 11，需要 .NET Framework 4.8。无需安装；移动应用时，把 `牛马统计.exe`、`牛马统计.exe.config` 和 `data/` 一起移动。

默认关闭窗口会收起到系统托盘，继续统计。双击托盘图标恢复窗口；右键托盘选择「退出」才会停止程序。可在设置中调整关闭行为，登录自动启动默认关闭。

## 功能

| 功能 | 内容 |
| --- | --- |
| 屏幕统计 | 开屏、活跃、非活跃时长及活跃占比 |
| 软件统计 | 前台活跃时长、使用占比、各软件键鼠次数 |
| 实时键鼠 | 按键次数；左键、右键、中键及侧键点击；横向和纵向滚动；鼠标移动像素距离 |
| 软件分类 | 自动分类、自定义分类、分类筛选、排除软件 |
| 历史趋势 | 按天查看、24 小时时段统计、最近 7 天活跃趋势 |
| 牛马日报 | 当前日期的 PNG 日报，可预览、复制和保存 |
| 迷你窗口 | 默认 306 × 192，置顶、边缘吸附、可选贴边收起、位置与尺寸记忆 |
| 外观 | 奶油白、深色、跟随 Windows |
| 数据管理 | ZIP 备份恢复、单日及批量 CSV、旧记录清理、排除管理 |

### 实时键鼠

键鼠计数独立于图表刷新。输入按 **75 毫秒短批次**合并，主窗口、迷你窗和已显示的软件行同步更新；通常约 0.1 秒可见，实际延迟受系统负载影响。没有输入时，快速刷新定时器停止。

长按连发只计第一次按下，松开后再次按下才增加次数。修饰键也计数；系统模拟输入不累计。滚动一格按 Windows 标准 120 单位计算，精细滚动保留小数。移动距离以屏幕像素计，不换算厘米。

查看历史日期时，当天仍继续采集，历史数字保持不变。隐藏或最小化窗口时停止界面刷新，恢复后显示最新统计。监听回调中断时会自动尝试恢复，中断期间的次数无法追溯。

### 软件分类

在「软件」页点击软件右侧标签，调整分类或排除统计。「管理分类」支持自定义分类，最多 12 个；删除分类后，相关软件归入「其他」。分类调整也用于历史展示和日报。

常见开发、设计、办公软件自动归入「工作」，沟通软件归入「沟通」；浏览器等用途不确定的软件默认「其他」，可自行调整。

排除只影响之后的采集，不删除已有记录。被排除的软件不累计活跃时长和键鼠次数，开屏时间继续累计。

### 牛马日报

点击底部「日报」，生成选中日期的 **1120 × 1520 PNG**，包含活跃时长、键鼠次数、前四名软件、分类占比和小时节奏。支持预览、复制图片和保存，不会自动发送。当日数据以生成时刻为准。

### 小窗与操作

- 顶部图钉切换置顶，斜箭头切换完整窗口和迷你窗。
- 完整窗口与迷你窗分别记住位置和尺寸，更换显示器后自动调整到可见区域。
- 迷你窗距离屏幕边缘 18 个逻辑像素以内自动吸附。
- 设置中可开启「贴边后自动收起」：靠左或右边缘时，移出收起，移入展开，默认关闭。
- 点击「暂停 / 继续」控制所有统计；快捷键 **Ctrl + 空格**仅在本窗口内生效。
- 底部下载按钮导出选中日期的 CSV；「趋势」页可点击日期柱查看当天。

## 统计口径与隐私

只统计**程序运行期间**的使用，无法追溯启动前的数据。

开屏指当前会话解锁且显示器亮起的运行时间；锁屏、显示器关闭和睡眠期间不累计。超过空闲阈值没有操作，归入非活跃时长，仍保留开屏时间。设置支持 30 秒、1 分钟、2 分钟或 5 分钟空闲阈值。

活跃依最近一次用户输入判断，安静阅读或看视频可能归入非活跃。软件时长按前台窗口每秒采样，快速切换可能有约 1 秒的归属偏差，后台软件不累计。部分受保护进程会显示进程名或「桌面 / 系统」。这些统计描述使用习惯，不代表工作产出。

**键盘只保存次数，不保存输入内容；鼠标不保存位置轨迹。** 不读取窗口标题，不采集截图。软件记录包含名称与可执行文件路径，用于区分同名程序。

## 数据与备份

正式记录保存在可执行程序旁的 `data/` 中，首次运行时自动创建。分享的程序目录不附带统计记录、个人设置、测试输出或备份；正常启动不会填充演示数据。

```text
data/
  settings.json            分类、排除、外观与窗口偏好
  settings.json.bak        上一次保存的设置备份
  days/YYYY-MM-DD.json     每日汇总，含小时和软件数据
  days/*.json.bak          上一次保存的统计备份
  backups/*.zip            数据管理与程序更新前的安全备份
```

每 10 秒保存一次，正常退出也会保存。写入采用临时文件和原子替换；主文件损坏时尝试恢复备份，并保留损坏文件供排查。异常结束可能丢失最后约 10 秒的数据。默认保留最近 90 天，可在设置中选择 7、30、90 或 365 天。

底部「数据」提供以下操作：

- **ZIP 备份**：保存每日记录、分类、排除与偏好，不含程序或 Windows 启动项。
- **ZIP 恢复**：校验后预览日期，默认只补齐缺失日期；覆盖同日期、恢复偏好需要主动勾选。
- **批量 CSV**：每个已有日期导出一个文件，存入独立子目录。
- **清理旧记录**：确认后删除截止日期之前的记录，今天始终保留。
- **排除管理**：恢复被排除软件的采集。

恢复或手动清理前自动创建安全备份；恢复中写入失败会尝试回滚。安全备份不自动过期，可按需整理。

手动复制 `data/` 前请退出程序。移动应用后，如已开启登录启动，在设置中关闭再开启以更新启动路径。

## 源码与开发

使用 C#、WPF 和 Windows 原生 API，无第三方运行依赖。输入钩子运行在独立消息线程；时长每秒采样，时长和图表每 2 秒刷新，软件排行每 5 秒重排，趋势每 15 秒刷新。软件行与小时图复用，软件列表每页最多 50 项；图标、历史和进程缓存分别限制为 64 项、32 天和 256 项，未保存的历史数据在写入前保留。日报按需生成。

```text
牛马统计.exe             正式程序
牛马统计.exe.config      运行配置
data/                    首次运行后生成的正式记录与安全备份，不上传
src/                     C# 源码和窗口 XAML
assets/                  应用图标
build.ps1                编译脚本
test.ps1                 回归测试脚本
.editorconfig            PowerShell 脚本编码与换行约定
artifacts/               开发时生成的构建、测试、预览及导出文件，不上传
```

```powershell
# 用 Windows 自带的 C# 编译器构建，无需 .NET SDK；构建前退出正在运行的程序
.\build.ps1

# 执行回归测试，报告写入 artifacts/test-report.txt
.\test.ps1

# 可选：生成演示预览，使用独立目录，不写入正式记录
.\牛马统计.exe --demo --data-dir artifacts\preview-data --render artifacts\overview.png
```

构建和测试脚本支持 Windows PowerShell 5.1 与 PowerShell 7。含中文的 `.ps1` 文件使用 **UTF-8 with BOM** 编码，避免 Windows PowerShell 5.1 按系统编码读取后出现语法错误；编辑脚本时请保留该编码，`.editorconfig` 已设置对应规则。

版本 1.1.1 已通过 23 项回归检查，覆盖时间边界、统计归属、分类排除、备份恢复、CSV、真实 Windows 监听生命周期，以及实时输入合并、主窗 / 迷你窗 / 软件行更新、历史和隐藏窗口、退出前保存。

测试数据、测试报告和演示预览与正式记录独立。运行测试时，会在 `artifacts/test-data-*` 中生成独立数据，可在测试结束后删除；演示预览仅在显式使用 `--demo` 时生成。

## 上传 GitHub 或分享程序

分享目录保留程序、运行配置、源码、图标、构建与测试脚本、README 和 `.gitignore`。运行过程序后，先退出应用，再移除 `data/`、`artifacts/` 及额外导出的 CSV、日报和 ZIP 备份；这样不会携带个人软件路径、使用记录或窗口偏好。再次运行会重新生成本地数据目录。

`.gitignore` 已忽略运行数据、测试输出、备份、CSV、日报图片和日志。请通过 Git 提交上传；使用网页上传或打包分享时，需要自行排除这些文件。忽略规则不影响已经提交的文件，已有仓库应检查 Git 跟踪列表和历史提交。
